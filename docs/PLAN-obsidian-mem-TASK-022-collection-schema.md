## Prior art + risk spike (from RESEARCH-FINDINGS.md)

- The chunk_text `enable_analyzer` + BM25 Function → auto SparseFloatVector pattern is
  PROVEN on milvus-lite by memsearch (`/home/derek/src/memsearch/src/**/store.py:148-179`):
  content VARCHAR(65535) enable_analyzer + SPARSE_FLOAT_VECTOR auto-generated by BM25
  Function(content). Mirror it (index type COSINE/FLAT or IP for dense there; pick and pin).
- NOVEL RISK: no prior repo uses partition-key scope or ARRAY<VARCHAR> trigger filters on
  lite. Before finalizing, spike against the pinned milvus-lite build (throwaway script in
  scripts/spike-milvus.mjs, results into docs/research/): (a) `is_partition_key` on a VarChar
  with dynamic values (project slugs), (b) Array fields + ARRAY_CONTAINS/ARRAY_CONTAINSAny
  exprs, (c) hybrid_search dense+BM25. Documented fallbacks: (a) scope as plain scalar
  filter (accept perf loss), (b) comma-delimited VARCHAR + `LIKE` filters (worse; last
  resort), (c) dense-only + client-side keyword boost. Record outcomes in code comments.
